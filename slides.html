Human boundary

Current boundaries

What is not in v1 — and why

Private repository access

Public HTTPS GitHub URLs work today. Private GitHub/GitLab access needs OAuth, token handling, consent, and permission design.

Arbitrary code execution

The app runs only a reviewer-selected declared npm script. Docker is isolated; trusted local execution requires explicit confirmation.

Live AI explanation

No API key is embedded. Codex is a manual, explanation-only review step and never generates a verdict.

Teams and governance

Shared workspaces need authentication, tenant isolation, retention controls, and durable audit logging.
